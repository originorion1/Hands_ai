# Procurement price-leakage synthetic evaluation

`fixture.py` generates twelve fixed, label-free cases. `ground_truth.json` is opened only after every detector prediction is frozen. All methods see the same four purchase rows per case and the same January to March 2026 evaluation window. The cases exercise high prices, supplier differences, grade and delivery changes, pack units, FX, tax, missing contract, duplicate invoices, corrected history, contradictory contract and no anomaly. Labels are designed synthetic annotations, not independently verified customer outcomes.

Run `PYTHONPATH=src python -m evaluation.procurement_price_270.evaluate` from the repository root. The comparator includes contract threshold, historical mean and median, supplier comparison, and a duplicate/unit rule. The union catches all three designed positives, with six false positives; the ORION rule catches the same three with no false positives in this small fixture. Its exact arithmetic is Decimal-based; a held-out target of USD 17 per each against a conservative USD 11 reference and 10 units gives **USD 60 estimated exposure**. A second evaluation can win for the baseline. No realized saving is asserted.

The three-of-three candidate precision has a wide 95% Wilson interval, about 0.44–1.00. It does not satisfy the representative 80% target. Review time, request cost and compute cost are explicit assumptions; no actual customer baseline, analyst timing, network cost or financial outcome has been measured. Incremental validated discoveries and net economic value remain unknown.

The local drill uses the installed synthetic connector, one-use governed read, an offline tenant session, private source/evidence/witness files, a recomputed finding, authenticated API and the Command Center. The API rechecks the original source and report digests on each read. Mutating the source or finding makes the report unavailable; a corrected target in a new authorized synthetic run abstains and invalidates the prior candidate with a successor-linked private event. The browser clears its finding after access denial. The reviewer decision starts `pending`; a one-use authenticated synthetic review can be recorded in a private digest-bound event. This is a technical review-path test, not independent customer adjudication.
