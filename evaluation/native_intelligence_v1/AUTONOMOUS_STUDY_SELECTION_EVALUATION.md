# Autonomous study-selection evaluation

`src/orion/learning/epistemic_selection.py` is a proposal-only finite Bayesian selector. It requires a tenant-bound understood structure, explicitly allowed record target, verified calibration evidence IDs, a finite two-hypothesis prior, and bounded request/privacy/operational costs. It scores expected entropy reduction times relevance divided by request cost. Hard authorization and risk filters run before scoring; only the governed discovery runner reads evidence. It has no grant, connector, execution, or knowledge-promotion interface.

The first comparison uses the existing planner's alphabetically ordered authorized record sampling as `existing`; `fixed` takes fixture order; `random` uses a deterministic case seed; `heuristic` uses the training-derived largest likelihood separation per request; `learning_progress` uses training calibration volume as a weak proxy; `frozen_nonlearning` is the same unchanged existing policy. All seven methods see the same structural metadata and training calibration, have the same allowed targets, and make two governed reads per case. Beliefs are updated after each read. The heuristic is a strong and fair baseline, not a strawman. No method sees held-out labels before sealing predictions.

On 72 held-out cases, enhanced found 11/21 designed positives with zero false positives; existing found 7/21 with two false positives; the strong heuristic also found 11/21 with zero false positives. Enhanced realized information gain was 0.185 bits/read, existing 0.112, heuristic 0.154. Enhanced and heuristic had identical designed hit sets. The paired 95% case-bootstrap interval for enhanced minus existing true-positive rate includes zero (−0.0139 to 0.1389); discordant exact two-sided p=0.289. Enhanced minus heuristic designed-hit difference is exactly zero in this split. In shifted transfer, enhanced and heuristic again found 10/27 with four false positives each; enhanced's realized information gain fell to 0.123 bits/read and heuristic's was 0.133. Results do not justify adopting the Bayesian policy in the product.

The old nine-positive fixture remains unchanged in `evaluation/pr279_study_selection`; its missing seed signal cannot establish information-gain model quality. This new lab is a separate experiment. The next falsifiable test is an independently generated, preregistered multi-entity lab where a calibrated selector must beat the strong heuristic on validated discoveries or review minutes at equal read budget while maintaining false-positive and provenance limits. Do not use transfer labels for calibration of this frozen candidate.
