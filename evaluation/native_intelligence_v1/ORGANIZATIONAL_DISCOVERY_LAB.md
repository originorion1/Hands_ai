# Organizational discovery laboratory

The evaluator generates four disjoint splits with fixed seeds: training (96 organizations), development (24), holdout (72), and transfer (72). Each split has three domains. Holdout uses mobility, utilities, and service; transfer uses manufacturing, energy, and distribution. Each organization has unfamiliar resource names, five structural questions, differing graph links, one hidden or forbidden target in some cases, and two authorized reads per method. Records can be flagged, clear, or missing. A latent designed issue affects answer probabilities; transfer changes two likelihoods after calibration. No selector imports `generate_lab.py` or reads evaluation labels. Test-pinned hashes make split changes visible.

This is a **small probabilistic question-selection lab**, not a realistic model of an organization. It contains ambiguous and misleading observations, missing or delayed records, and domain/schema vocabulary changes, but it does not implement real temporal effects, confounding graphs, economic outcomes, entity resolution, or independent adjudication. The binary issue is a designed synthetic label. The generator and selection code share a development repository, so separation is by module, sealed commit, and evidence order rather than an independent lab operator. Reproduction must retain that limitation.

The policy, generator, calibration, and split files were frozen at commit `b09d37bffb6b755b3973dc351023f0bef8ed8c59`, tree `e073e5c92fb7034ba8c56e8371d619e3bec8e703`, before holdout predictions were generated. `calibration.json` SHA-256 is `762f33d44b2a1f262d4ee6480d360a7b3a0dd52bdc441f5b15b2917a9a453f61`. The prediction artifacts are stored outside the source tree under `/home/orion/evidence/orion-native-intelligence-v1/`; their digests are in the release packet. No post-holdout policy tuning is allowed within this experiment.

Reproduce with `PYTHONPATH=src python3.12 -m evaluation.native_intelligence_v1.benchmark --cases evaluation/native_intelligence_v1/holdout_cases.json --calibration evaluation/native_intelligence_v1/calibration.json --output <prediction-file>` and then `PYTHONPATH=src python3.12 -m evaluation.native_intelligence_v1.score --cases evaluation/native_intelligence_v1/holdout_cases.json --labels evaluation/native_intelligence_v1/holdout_labels.json --predictions <prediction-file> --output <score-file>`. Elapsed compute time varies across hosts; compare selections, evidence identities, and statuses rather than byte-identical timing.

Next independent lab should be generated by someone other than the method author, use realistic multi-entity source records and causal alternatives, hide labels outside the development repository, and pre-register economic and abstention metrics before access.
