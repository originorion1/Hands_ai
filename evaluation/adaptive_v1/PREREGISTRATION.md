# Adaptive study-selection preregistration

Frozen before generating or scoring new unseen cohorts. This file and the
selector/generator source must be committed before `unseen_a`, `unseen_b`, or
`unseen_c` data are materialized. Existing PR #282 holdout and transfer files
are read only for post-seal failure diagnosis and are never selector inputs.

## Candidate and comparator

The four methods are existing ORION, enhanced ORION, the strong heuristic,
and `adaptive_hybrid`. Hybrid uses the same training-only calibration and
governed two-record read path. Its only changed rule is expected reduction in
the already frozen candidate/abstain decision loss, with information gain as a
tie-break. All methods have identical visible/permitted question sets, two
attempted reads, tenant binding, source records and read-only authority.
No outcome-updated model is used in the four-way run: no independent reviewer
has been appointed. A separate update gate is tested with synthetic mocks.

## Unseen evaluation and no-retuning rule

Three independently seeded 72-organization cohorts are generated by the
evaluator-only `generate_unseen.py`, after this source is frozen. Cohorts vary
domain vocabulary, prevalence, signal strength and missingness. Designed
labels remain outside the case files and are opened only after prediction
files are hashed. No policy or calibration change is permitted after looking
at these scores. The generator is a synthetic model family and does not
constitute independent real-world adjudication.

## Primary comparison

Primary utility per organization is `TP - 2*FP`, since false review candidates
consume time. Compare paired hybrid minus heuristic utility across all 216
organizations, with a seeded 10,000-resample percentile 95% interval. An
incremental *synthetic* selection improvement requires: positive lower
interval bound, no worse aggregate false-positive count, and positive utility
difference in at least two of the three cohorts. Otherwise the strong
heuristic remains the default. Actual analyst minutes and monetary values
are unavailable; candidate-review count is only a workload proxy. Neither
synthetic success nor the mock outcome-update test proves independent
adjudication or economic value.

## Secondary measures and gates

Report designed TP, precision, recall, FP, abstentions, realized information
gain per request, request count/cost, compute latency, Brier score, provenance
completeness and review queue size for each cohort and method. Preserve report
digest and source-record checks. Reject any run with unequal budgets,
cross-tenant acquisition, altered source digest, unauthorized target, writes
or `execution_allowed=true`. Treat WSL as diagnostic; stable Linux remains
unqualified without an authorized host.
